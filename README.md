# KCD São Paulo 2026 ☸️ 🇧🇷

This repository documents my participation and key takeaways from **Kubernetes Community Days (KCD) São Paulo 2026**, held on September 26, 2026, in São Paulo.

The event brought together the Brazilian Cloud Native community to discuss Kubernetes, Platform Engineering, Security, Observability, AI, and Open Source.

## 📅 Event

- **Event:** Kubernetes Community Days — São Paulo 2026
- **Date:** September 26, 2026
- **Location:** Nubank Spark — São Paulo, Brazil
- **Format:** In-person

🔗 [Official Event Page](https://community2.cncf.io/events/details/cncf-kcd-brasil-presents-kcd-sao-paulo-2026/)

## 💡 Key Takeaways

Three topics stood out to me:

**Platform Engineering** — Self-service platforms, IDPs, Golden Paths, and GitOps are helping teams reduce manual processes and operational friction.

**Security by Design** — Identity, admission policies, supply chain security, and runtime controls are becoming part of the platform itself.

**AI + Cloud Native** — AI Agents introduce new challenges around identity, permissions, guardrails, and security in Kubernetes environments.
